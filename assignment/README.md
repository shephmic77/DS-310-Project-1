# Assignment

This project was completed for DS 310 at Penn State in Fall 2026.

The task was to take part in a regression competition on Kaggle. Models were scored using mean squared error. Lower scores were better.

The required course submission was the final notebook or model and a report PDF of no more than 10 pages, including the cover. The report needed the team information, competition description, public leaderboard screenshot, preprocessing, feature choices, model comparisons, tuning, evaluation, ideas, and lessons learned.
