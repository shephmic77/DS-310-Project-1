# Versions

`Versions.zip` keeps the earlier notebooks, scripts, model results, logs, and prediction files in one place.

The archive contains 3,568 files. The `Older/` and `submissions/` paths describe the local project before the final GitHub cleanup. These are historical experiments, not the notebook needed to run the final model.

`archive_manifest.csv` lists every archived file, its size, and SHA256 hash. The same manifest is inside the ZIP. The archive was opened and every file hash was checked after it was created.

Local Python environments, packages, caches, temporary PDF images, and organization helper files are not part of the archive. The full original local folders are kept in `.local-backup/` and are ignored by Git.

For the finished model, use [the final notebook](../analysis/regression_analysis.ipynb).
